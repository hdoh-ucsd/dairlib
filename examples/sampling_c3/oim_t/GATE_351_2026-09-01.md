## Authority

The initial execution candidate is admitted only when all three independent
receipts pass:

```text
admitted = predicted_lateral_safe
        && swept_capsule_clear
        && live_ik_reached
```

The unchanged `0.005 m` lateral tolerance is now an execution authority, not
a diagnostic field. Acquisition is still evaluated for every dynamically
successful candidate so rejected candidates retain complete negative
evidence. Each record logs `acquisition_gate`, `lateral_gate`, and the combined
`admission_gate` separately.

If the admitted set is empty, the controller emits
`reason=initial_candidate_admission_failed` and exits with code 3. It no
longer throws or aborts on the empty task-space plan.
