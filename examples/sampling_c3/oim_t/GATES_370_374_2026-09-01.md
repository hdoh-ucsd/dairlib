## Result

These gates make Drake contact evidence inspectable without changing controller
admission, solver behavior, costs, contact parameters, or task tolerances.

| Gate | Implemented acceptance evidence | Result |
| ---: | --- | :---: |
| 370 | Classify each measured xArm-stick/T point-pair receipt as `tip_side_candidate`, `side_shaft`, `top_graze`, or `bottom_graze` using the existing pusher radius and contact-activation tolerance. The label is diagnostic and does not claim selected-face acceptance. | PASS |
| 371 | Write the maximum-force stick/T point receipt at every active 2 ms observation to a new `contacts.jsonl`, including force, penetration depth, world contact point, object-relative height, point-to-tip distance, episode, and class. Existing result directories are still refused rather than overwritten. | PASS |
| 372 | Draw the measured capsule segment, tip, and contact point over the camera image and show instantaneous force/classification in the side panel. | PASS |
| 373 | Retain the nearest state frame and its neighbors for every high-rate contact receipt, while preserving the legacy begin/end-log fallback for older rollouts. | PASS |
| 374 | Synchronize the Python diagnostic model and wrapper with the canonical native six-joint xArm6 wrist, then verify old-log compatibility and a fresh closed-loop render. | PASS |

The classifier uses

```text
h = p_contact,z - p_object,z
d_tip = ||p_contact - p_tip||
b = r_pusher + contact_activation_tolerance

tip_side_candidate iff |h| <= b and d_tip <= 2 r_pusher + tolerance
side_shaft        iff |h| <= b and the tip condition is false
top_graze         iff h > b
bottom_graze      otherwise.
```

This is intentionally separate from the controller's initial lateral gate,
selected face, predicted prefix, measured dwell, and terminal acceptance.
