## Contact-state construction

For a sampled object-frame point transformed to `p_sample,W`, sampled outward
normal `n_W`, pusher radius `r`, object position `p_O`, end-effector position
`p_E`, sampled relative height `h`, and the existing activation tolerance
`epsilon`, the sampled C3 state now constrains

```text
n_W' (p_E - p_O) in [n_W' p_sample,W + r - epsilon,
                      n_W' p_sample,W + r + epsilon]
p_E,z - p_O,z       in [h - epsilon, h + epsilon].
```

This replaces an absolute-height-only constraint with the required
pusher-to-object relative state. Initial engagement still requires a
nonseparating measured gap. Once engaged, an explicit latched-continuation
predicate uses the existing activation band as hysteresis; that band cannot
manufacture first contact.

The C3 object rollout remains dynamically simulated for candidate scoring and
scientific diagnostics. The returned C3 pusher state is the execution
trajectory, matching the DAIRLab hybrid separation between object prediction
and commanded pusher motion. No solver iterations, horizon, ADMM values,
costs, contact parameters, random seeds, controller limits, or acceptance
tolerances were changed.

The raw three-iteration C3 ADMM consensus receipt remains a diagnostic
`FAIL` (`consensus_residual=17.8528`) while the independently checked dynamic
rollout passes. It was not hidden or retuned in this gate series.
